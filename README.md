# ASGD-Net

Official implementation of **ASGD-Net: An Intelligent Spectral Graph Diffusion Framework for Camouflaged Object Detection**.

## Overview

ASGD-Net is a camouflaged object detection framework designed to improve feature representation, cross-scale interaction, iterative refinement, and boundary-aware prediction.

The framework mainly consists of:

- Adaptive Spectral Graph Network (ASGN)
- Diffusion-based Progressive Decoder (DPD)
- Dual Attention Module (DAM)
- Multi-Scale Feature Enhancement (MSFE)
- Edge Detection Module (EDM)

## Datasets

The model is evaluated on the following camouflaged object detection datasets:

- CAMO
- CHAMELEON
- COD10K
- NC4K
- ACD1K
